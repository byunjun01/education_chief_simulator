# 교육수석 컨퍼런스 시뮬레이터

한 달(4주 또는 5주) 평일 달력에 컨퍼런스를 드래그해서 배정하는 도구입니다.

- 시작 월요일과 기간(4주/5주)을 고르면 평일 달력이 나옵니다. 공휴일은 회색으로 막혀 있습니다.
- 오른쪽 카드를 잡으면 담당 교수·전공의가 모두 가능한 날짜만 초록색으로 켜지고, 그 날짜에만 놓을 수 있습니다.
- 날짜를 더블클릭하면 휴무일로 지정하거나 해제합니다.
- 작업 내용은 브라우저에 자동 저장됩니다. **파일로 저장 / 파일 불러오기**로 다른 사람과 주고받을 수 있습니다.

## 개인정보

이 저장소와 사이트에는 실제 인원 정보가 없습니다. 입력한 이름과 휴가 날짜는 각자의 브라우저(localStorage)에만 저장되고, 어떤 서버로도 전송되지 않습니다.
실제 데이터를 담은 `.json` 파일은 저장소에 올리지 마세요.

## 실행

빌드가 필요 없는 정적 사이트입니다. GitHub Pages에서 그대로 배포되며, 로컬에서는 아래처럼 띄웁니다.

```bash
python -m http.server 8765
```
